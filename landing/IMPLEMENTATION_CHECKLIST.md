## ✅ PHASE 5: Google Search Console Setup (1 hour)

### Add Property
- [ ] Go to [search.google.com/search-console](https://search.google.com/search-console)
- [ ] Click "Add property"
- [ ] Enter: `https://stockhive.co.ke`

### Verify Ownership
- [ ] Choose "DNS record" verification method (easiest)
- [ ] Copy TXT record provided by Google
- [ ] Go to domain registrar DNS settings
- [ ] Add TXT record with Google's verification code
- [ ] Return to Search Console
- [ ] Click "Verify"
- [ ] Wait for verification (5-30 minutes)

### Submit Sitemap
- [ ] In Search Console, click "Sitemaps" (left menu)
- [ ] Enter: `https://stockhive.co.ke/sitemap.xml`
- [ ] Click "Submit"
- [ ] Wait for "Success" message

### Request Indexing
- [ ] Go to Search Console "URL Inspection" tool
- [ ] Paste: `https://stockhive.co.ke/`
- [ ] Click "Request Indexing"
- [ ] Google will crawl within 48 hours

## 🚨 Troubleshooting

### Landing page not showing
- [ ] Wait 5-10 minutes for DNS propagation
- [ ] Clear browser cache (Ctrl+Shift+R on Windows)
- [ ] Check domain registrar DNS records are correct
- [ ] Verify SSL certificate is installed

### Images not showing
- [ ] Check `/landing/images/` folder exists
- [ ] Verify image file names match HTML
- [ ] Check image file sizes (must be < 200KB)
- [ ] Use absolute paths: `/landing/images/hero.png`

### Google can't find page
- [ ] Wait 24-48 hours (indexation takes time)
- [ ] Manually request indexing in Search Console
- [ ] Check robots.txt doesn't block homepage
- [ ] Verify sitemap.xml is valid: https://stockhive.co.ke/sitemap.xml

### Page slow (Lighthouse < 90)
- [ ] Compress images further with TinyPNG or Squoosh
- [ ] Remove unnecessary JavaScript
- [ ] Check waterfall chart in GTmetrix for bottlenecks
- [ ] Verify hero image is preloaded

### Search Console shows errors
- [ ] Check canonical URL is correct
- [ ] Verify meta tags are valid
- [ ] Check page is accessible (not blocking in robots.txt)
- [ ] Test with [Rich Results Test](https://search.google.com/test/rich-results)
